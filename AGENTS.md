# Работа с ThinkCaps

ThinkCaps — русскоязычное Android-приложение для изучения английского. Экран и логика повторения написаны на Flutter/Dart, SQLite и системные интеграции реализованы в Kotlin. Начните с [карты кода и руководства по разработке](docs/development.md).

## Рабочий цикл

- Перед правками проверьте `git status --short` и существующий diff. Сохраняйте пользовательские изменения. Для параллельных задач используйте отдельные Git worktree.
- Найдите основной сценарий, связанный тест и соседние контракты. Для исправления воспроизводимого дефекта добавьте проверку, которая падает до исправления. Для нескольких этапов ведите краткий план в текущем чате.
- Держите diff в рамках задачи. Если меняете пользовательский сценарий, архитектурный контракт или процесс сборки, обновите соответствующий раздел документации.
- Перед сдачей запустите `pwsh -NoProfile -File tool/check.ps1` или `powershell -NoProfile -File tool/check.ps1` в Windows. Для изменений Kotlin, мостов, зависимостей Flutter и Android-сборки используйте режим `android`. Для SQLite запустите режим `device -DeviceId <id>` на тестовом Android и проверьте миграцию со старой БД, если менялась схема. Для изменений Android-поведения выполните затронутые сценарии из [списка ручных проверок](docs/development.md#ручные-проверки).
- Проверьте итоговый diff и `git diff --check`. В результате перечислите выполненные проверки, ограничения проверки и значимые решения.

## Контракты и данные

- Сохраняйте независимость расписаний EN → RU и RU → EN. При редактировании слова сохраняйте ID и оба расписания. Изменения схемы SQLite требуют повышения версии, миграции существующих данных и проверки обновления.
- Меняйте Dart и Kotlin согласованно при изменении `app.thinkcaps/bridge`. Сверяйте имена методов, аргументы, типы результатов и коды ошибок. Поддерживайте отмену выбора файла, отсутствие сети до загрузки модели и отсутствие английского голоса.
- Сохраняйте русские пользовательские тексты и атрибуцию Google Translate. Для импорта используйте синтетический текст и изображения, для тестов Android — debug-пакет `app.thinkcaps.android.debug`.
- Ключи, пароли, локальные настройки SDK, APK и данные устройства держите вне Git. Не очищайте данные приложения и не заменяйте релизную установку для проверки. Подпись и публикацию релиза выполняйте только по явной задаче.
